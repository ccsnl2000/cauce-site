VisitasSe conectan con Cloudflare Web Analytics

Para ver aquí visitas, páginas y países en vivo, necesitamos un token de solo lectura de Cloudflare. Mientras tanto, las cifras están en el panel de Cloudflare.

  1. Cloudflare → My Profile → API Tokens → Create Token → plantilla "Read analytics and logs".
  2. Pega el token en Supabase → Edge Functions → Secrets con el nombre CF_API_TOKEN.
  3. Avísanos y activamos la pestaña.

WhatsAppMensajes en vivo con WhatsApp Business

Para ver y responder chats de WhatsApp aquí, hace falta WhatsApp Business Platform (Meta) con un número dedicado de Cauce. Requiere verificar el negocio en Meta, así que conviene hacerlo cuando Cauce esté registrada.

Mientras tanto, el asistente del sitio guarda cada conversación en la pestaña Conversaciones, y el botón "Seguir por WhatsApp" abre un chat directo con el número que indiques.
